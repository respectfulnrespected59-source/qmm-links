Install your crew.Claude Code and the Everything Claude Code skills, in your terminal.

From a brand-new computer to an AI crew with 71 agents and 408 skills. Quantus and Tess walk you through every step on real footage. Then your crew's first job is making the key that unlocks Lesson 2.

What you need

  • A computer: Windows 10 or 11, macOS 13 or newer, or Linux
  • A paid Claude plan: Pro or higher. The free Claude plan doesn't include Claude Code.
  • About 15 minutes
The steps

Every command from the video.

  1. Open a terminal

    Windows: press Windows + X, then click Terminal (on Windows 10: Windows PowerShell). Mac: press Cmd + Space, type Terminal, press Enter.

  2. Install Claude Code

    Windows PowerShell

    irm https://claude.ai/install.ps1 | iex

    Mac, Linux or WSL

    curl -fsSL https://claude.ai/install.sh | bash

    It shows no progress while it downloads. Give it a minute.

  3. Check it

    Open a new terminal window, then run:

    claude --version

    You should see a version number like 2.1.316 (Claude Code). For a full health check:

    claude doctor

  4. First launch and sign in

    mkdir my-first-project
    cd my-first-project
    claude

    Your browser opens to sign in with your Claude account. Approve it, come back to the terminal, and your crew is ready. Type /exit when you want to leave.

  5. Drop in the stack: Everything Claude Code

    Back in your normal terminal (not inside Claude), run these one at a time:

    claude plugin marketplace add https://github.com/affaan-m/ECC
    claude plugin install ecc@ecc
    claude plugin details ecc@ecc

    The last one lists everything you just added: the agents, the skills and the hooks.

  6. Red error the first time you start Claude?

    That's a known ECC issue (#2822): the plugin installs without a few files it needs. Don't fix it yourself. Start claude and tell your crew, the way the video does:

    there's a red ECC hook error at startup, fix it
Going further (optional): Ruflo

Inside Claude Code, the video's next step adds Ruflo from its GitHub page:

/plugin marketplace add ruvnet/ruflo
/plugin install ruflo-core@ruflo
