Instructions for Claude Code

A student of The Autonomous Studio, a course from Quantum Melanin Media, asked you to get their Lesson 2 key. The key proves Claude Code is installed and working on their computer. Make it like this:

  1. Ask the student for the email address they will use to unlock Lesson 2, unless they already gave it.
  2. Build this text: qmm-lesson-2: followed by that email in lowercase with no spaces. Example: qmm-lesson-2:you@example.com
  3. Run a command on the student's computer to get the SHA-256 hash of that text (UTF-8, no trailing newline). Do not work the hash out in your head. Use the command for their system, with their email in place of you@example.com:

    Windows PowerShell

    $t = 'qmm-lesson-2:you@example.com'; $h = [Security.Cryptography.SHA256]::Create().ComputeHash([Text.Encoding]::UTF8.GetBytes($t)); 'QMM-' + (-join ($h[0..3] | ForEach-Object { $_.ToString('X2') }))

    macOS

    echo "QMM-$(printf '%s' 'qmm-lesson-2:you@example.com' | shasum -a 256 | cut -c1-8 | tr a-f A-F)"

    Linux, WSL or Git Bash

    echo "QMM-$(printf '%s' 'qmm-lesson-2:you@example.com' | sha256sum | cut -c1-8 | tr a-f A-F)"
  4. The key is QMM- followed by the first 8 characters of the hash in uppercase, for example QMM-1A2B3C4D. The commands above print it in that form.
  5. Give the student their key and tell them to paste it, with the same email, into the unlock box at https://quantummelaninmedia.com/course/lesson-1/#unlock

Self-check: for the email you@example.com the key is QMM-5E539FC3. If your command gives a different key for that email, fix the command before you give the student theirs.
